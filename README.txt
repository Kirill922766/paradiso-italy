PARADISO ITALY v4

ВАЖНО:
Эта версия запускается ОТДЕЛЬНО на порту 8765.
Она не использует 8000, поэтому не должна открывать вашу лабораторную.

1) Распакуйте ZIP.
2) Дважды нажмите START_SERVER.bat.
3) Откроется магазин:
   http://127.0.0.1:8765/
4) Админка:
   http://127.0.0.1:8765/admin.html
5) Пароль по умолчанию:
   admin123

Если хотите открыть админку отдельно — нажмите OPEN_ADMIN.bat.
Чёрное окно START_SERVER.bat не закрывайте.

В админке:
- добавление/удаление товаров;
- редактирование названия, артикула, категории, цены;
- размеры;
- описание;
- загрузка фотографий;
- просмотр и удаление заказов;
- телефон, Telegram, адрес;
- смена пароля.

Пока цены стоят 0 / "цена уточняется", потому что реальные цены не были указаны.
Размеры тоже можно изменить в админке.

Данные хранятся локально:
data/products.json
data/orders.json
data/settings.json
data/admin.json

Это локальная версия для проверки. Для настоящего интернет-магазина нужно будет перенести backend на хостинг с HTTPS и базой данных.

ПРОВЕРКА С ТЕЛЕФОНА В ДОМАШНЕЙ WI-FI:
1. ПК и телефон подключите к одной Wi-Fi сети.
2. Запустите START_SERVER.bat.
3. На ПК откройте CMD и выполните ipconfig.
4. Найдите IPv4 Address, например 192.168.1.105.
5. На телефоне в браузере откройте http://192.168.1.105:8765/
6. Если Windows Firewall спросит разрешение для Python — разрешите доступ в частной сети.
